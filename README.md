# README.md

Discover Regina — Virtual Tour
A Figma prototype exploring three landmarks in Regina, Saskatchewan.
Project overview
This project is an interactive virtual tour designed to introduce visitors to Regina's landmarks through images, descriptions, and clickable navigation.
Featured landmarks
Wascana Centre
Saskatchewan Legislative Building
Royal Saskatchewan Museum
Features
Home page with landmark cards
Separate pages for each landmark
Interactive image transitions
Smart Animate zoom effect
Navigation between pages
Tools used
Figma
GitHub
